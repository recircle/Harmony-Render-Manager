# GUI for ToonBoom Harmony batch renderer. 

## Overview
You can drag and drop directories containing .xscene directories and the program will scan all subdirectories for .xscene files and add them into the table modifying the name based on the .xscene nam.
Or you can drag and drop individual .xscene files directly.

## 
XML will be scanned and write mode XElement export node will be inserted and a copy of original .x scene will be saved. You can choose your PRORES flavor in the bottom dropdown.
## 
You can render each .xscene individually row by row or send everything to batch.
